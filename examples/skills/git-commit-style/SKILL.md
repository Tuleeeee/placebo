# Team commit style

- Start the subject line with a capitalized verb ("Add", "Fix", "Remove").
- Subject at most 50 characters; wrap the body at 72.
- One logical change per commit. If the diff mixes concerns, suggest splitting it.
- Never include generated files or secrets in a commit.
